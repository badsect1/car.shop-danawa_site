# 🚗 자동차 최신 뉴스 자동 수집 & AI 블로그 원고 작성 봇

최신 자동차 전문 매체(모터그래프, 오토데일리 등)의 뉴스를 실시간으로 감지하고, **기사 본문과 대표 이미지를 추출**한 뒤, **Google Gemini AI를 통해 검색 노출(SEO)에 최적화된 고품질 블로그 포스팅 원고와 3줄 요약을 자동 생성**하여 **구글 스프레드시트와 로컬 CSV에 실시간 저장**하는 자동화 솔루션입니다.

---

## 🌟 왜 유튜브 요약 대신 뉴스 기반 원고인가요?

1. **100% 안정적인 수집**: 유튜브의 봇 차단, 자막 미제공 등의 문제 없이 기사 전문을 안정적으로 크롤링합니다.
2. **높은 텍스트 신뢰도**: 제원, 가격, 배터리, 결함/리콜 등 검증된 팩트 중심 데이터를 바탕으로 작성됩니다.
3. **네이버/구글 검색 유입(SEO) 극대화**: 실시간 검색량이 높은 신차 출시, 프로모션, 정책 변경 등 트렌드 키워드를 선점할 수 있습니다.
4. **유사문서 페널티 회피 (AI 전면 재작성)**: 기사를 그대로 복사하지 않고, 전문 에디터 어조로 독자 관점(구매 가이드, 장단점 비교, 추천 대상)에서 완전히 새롭게 재구성합니다.

---

## 📌 주요 특징

- 📰 **대표 자동차 매체 실시간 감지**: 모터그래프, 오토데일리, 구글 뉴스 등 RSS 기반 무제한 수집
- 🖼️ **고화질 대표 이미지(og:image) 자동 연동**: 원고 상단에 이미지 URL을 함께 제공하여 블로그 작성 시 편의 제공
- 🤖 **Gemini 3.5 Flash 기반 고품질 원고 작성**:
  - 1. 바쁜 독자를 위한 **핵심 3줄 요약**
  - 2. 클릭률(CTR)과 검색 최적화(SEO)를 고려한 **추천 제목 3가지**
  - 3. 서론 - 소제목별 본론 - 에디터 총평 및 구매 가이드 형태의 **완성형 블로그 원고**
  - 4. 네이버/티스토리/워드프레스용 **추천 해시태그**
- 🛡️ **AI 모델 자동 폴백(Fallback) 방어**: 특정 AI 모델 과부하(503) 발생 시 백업 모델로 자동 전환되어 중단 없는 처리
- 📊 **구글 시트 연동 + 로컬 백업**:
  - 구글 스프레드시트(`자동차_뉴스_블로그` 워크시트)에 실시간 행 추가
  - 고유 ID 기반으로 **이미 처리된 기사 중복 작성 자동 방지**
  - 서비스 계정 키가 없거나 연결이 끊겨도 `results_backup.csv`에 상시 백업

## 📂 프로젝트 구조

```text
e:/youtube_summary_bot/
├── modules/
│   ├── news_collector.py      # RSS 뉴스 파싱, 기사 본문 및 이미지 크롤러
│   ├── ai_summarizer.py       # Gemini AI 블로그 원고 & 3줄 요약 생성기
│   ├── sheet_manager.py       # 구글 시트 쓰기 및 로컬 CSV 백업 매니저
│   ├── youtube_monitor.py     # (기존 유튜브 모듈 백업)
│   └── transcript_extractor.py# (기존 자막 모듈 백업)
├── .env                       # Gemini API 키 및 구글 서비스 계정 설정
├── config.json                # 뉴스 수집 소스 및 수집 설정
├── main.py                    # 파이프라인 메인 실행 파일
├── requirements.txt           # 파이썬 의존성 패키지
├── results_backup.csv         # 생성된 블로그 원고 로컬 백업 파일
└── run.log                    # 실행 로그 파일
```

## 🚀 실행 방법

### 1회 즉시 실행 (신규 기사 수집 & 블로그 원고 작성)
```bash
python main.py
```

### 백그라운드 자동 주기 실행 (기본값: 12시간마다 / 하루 2회)
```bash
python main.py --watch
```
- 필요에 따라 간격을 변경할 수도 있습니다 (예: 6시간 간격은 `--interval 360`).
- 새 기사가 등록될 때마다 자동으로 블로그 글을 생성하여 구글 시트와 CSV에 쌓아둡니다.
- 중복된 기사는 자동으로 건너뜁니다.
